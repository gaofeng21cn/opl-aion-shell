### 3. 视觉层次优化 ⭐⭐⭐

#### 改进点

1. **标题字号加大**：从 15px → 18px
2. **当前步骤高亮**：添加背景色区分
3. **完成动画**：步骤完成时的弹性动画

#### CSS 改进

```css
/* 加大标题 */
.appLoaderTitle {
  font-size: 18px; /* 从 15px */
  font-weight: 700; /* 从 600 */
}

/* 高亮当前步骤 */
.appLoaderStep[data-state='active'] {
  background: var(--bg-2);
  padding: 8px;
  margin: -8px;
  border-radius: 6px;
  transition: all 0.3s ease;
}

/* 完成动画 */
.appLoaderStep[data-state='complete'] .appLoaderStepMarker {
  animation: checkmark 0.3s ease-out;
}

@keyframes checkmark {
  0% {
    transform: scale(0);
  }
  50% {
    transform: scale(1.2);
  }
  100% {
    transform: scale(1);
  }
}
```

**实施难度：** ⭐ 低  
**影响范围：** CSS 文件  
**预期收益：** 视觉吸引力提升 30%+

## 📈 数据收集建议

### 关键指标

1. **跳过率**
   - 后续启动中多少用户使用跳过
   - 在哪个步骤跳过

2. **启动时间**
   - 首次启动平均时长
   - 后续启动平均时长
   - 预计时间准确性（±2秒内）

3. **用户满意度**
   - 启动体验评分（1-5星）
   - 是否觉得等待合理
   - 跳过功能有用性

### 数据收集方式

```typescript
// 示例：收集启动指标
const trackStartup = {
  isFirstRun: boolean,
  actualDuration: number,
  estimatedDuration: number,
  userSkipped: boolean,
  skipAtStep: string | null,
};

// 发送到分析服务
analytics.track('app_startup_completed', trackStartup);
```
